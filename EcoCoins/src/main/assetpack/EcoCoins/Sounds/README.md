# EcoCoins redeem sound

Place this file manually in your exported assetpack:

- `ExportedAssetPack/EcoCoins/Sounds/Redeem.ogg`
- `ExportedAssetPack/EcoCoins/Sounds/tick_timer_sound.ogg`
- `ExportedAssetPack/EcoCoins/Sounds/cancel_operation.ogg`

SoundEvent definitions used by EcoCoins:

- `ExportedAssetPack/Server/Audio/SoundEvents/SFX_EcoCoins_Redeem.json`
- `ExportedAssetPack/Server/Audio/SoundEvents/SFX_EcoCoins_TickTimer.json`
- `ExportedAssetPack/Server/Audio/SoundEvents/SFX_EcoCoins_CancelOperation.json`


Do not duplicate `SFX_EcoCoins_Redeem` in multiple SoundEvents folders.
