# EcoCoins redeem sound

Place your redeem sound file here as:

- `Redeem.ogg` (opcional, si vas a usar `SFX_EcoCoins_Redeem`)

The default sound event definition is in:

- `Server/Audio/SoundEvents/SFX_EcoCoins_Redeem.json` (opcional, puedes crearlo en el assetpack exportado)

You can reference this event from your item interaction using:

- `LocalSoundEventId: "SFX_EcoCoins_Redeem"`


If no custom sound event exists, EcoCoins falls back to `SFX_UI_Craft`.
